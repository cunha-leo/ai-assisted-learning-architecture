# Template reutilizável

Copie esta estrutura para iniciar uma nova implementação.

```text
curso/
└── disciplina/
    ├── 00-ArquivosGerais/
    ├── 01-Apresentacao/
    ├── 02-Temas/
    │   └── Tema-01/
    │       ├── Bloco-01/
    │       │   ├── 01-Capturas/
    │       │   ├── 02-Transcricao/
    │       │   ├── 03-Resumo-e-Debate/
    │       │   ├── 04-Infografico/
    │       │   └── 05-Podcast-de-Estudo/
    │       └── 90-Consolidacao-do-Tema/
    └── 06-Avaliacao/
```

Adapte o número de Temas e Blocos ao curso real. Não assuma uma quantidade fixa.
