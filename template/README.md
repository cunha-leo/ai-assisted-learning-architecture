# Template reutilizável

Esta pasta contém o esqueleto neutro da arquitetura.

Não é necessário copiar a estrutura cegamente. Adapte a hierarquia ao curso real, mantendo os princípios de:

- separação entre fontes e derivados;
- continuidade;
- estado persistido;
- proveniência;
- consolidação;
- operação multi-IA.

Comece por [GUIA-DE-USO.md](GUIA-DE-USO.md).

Para entender cada camada em profundidade, veja o Tema 01 em `showcase/disciplina-exemplo/`, onde os READMEs explicam **o que entra, por que existe, como usar, nomenclatura e benefício**.
