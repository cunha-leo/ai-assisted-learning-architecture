# 03 — Resumo e Debate

Esta camada registra o entendimento construído após o estudo.

Durante o debate, use a IA para esclarecer conceitos, pedir exemplos, testar interpretações, relacionar ideias e corrigir dúvidas.

Depois, gere um **resumo de fixação** contendo ideia central, conceitos, relações, exemplos, ressalvas e síntese.

**Nomenclatura sugerida:** `Tema NN - Bloco NN - Resumo de Fixacao.md`.

O resumo serve de ponte entre a fonte bruta e os derivados de revisão.
