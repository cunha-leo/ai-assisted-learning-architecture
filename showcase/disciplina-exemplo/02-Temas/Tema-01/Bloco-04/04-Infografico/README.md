# 04 — Infográfico

Crie o infográfico somente depois de estudar, debater e resumir.

Use transcrição + capturas + debate + resumo como base. Escolha o formato que melhor represente o conteúdo: fluxo, linha do tempo, comparação, ciclo ou mapa.

O objetivo é revisão rápida, visualização de relações e memorização.

Na versão pública, remova branding que possa sugerir material oficial.
