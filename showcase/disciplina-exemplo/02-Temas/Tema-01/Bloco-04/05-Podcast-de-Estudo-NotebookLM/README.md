# 05 — Podcast de Estudo / Revisão Auditiva

Use os artefatos do próprio Bloco para criar uma revisão auditiva.

Fluxo sugerido no NotebookLM:
1. crie um caderno;
2. anexe transcrição, capturas, resumo, infográfico e Prompt Mestre;
3. mande ler primeiro o Prompt Mestre;
4. gere o resumo em áudio;
5. escolha idioma/modalidade/duração;
6. baixe o áudio e transcreva;
7. envie áudio + transcript ao agente para organização e proveniência.

A arquitetura é independente do NotebookLM; ele é apenas a ferramenta usada no piloto.
