# 02 — Transcrição da Videoaula

Converta o conteúdo falado da aula em texto para facilitar busca, indexação, leitura e uso pela IA.

```text
Videoaula → ferramenta de transcrição → TXT/MD → limpeza opcional → debate
```

Preserve data, motor de transcrição e estágio (`raw`, `clean`) quando existirem.

No showcase público, mantenha a posição arquitetural e use placeholder quando a transcrição original não puder ser redistribuída.
