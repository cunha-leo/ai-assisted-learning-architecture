# Prompt Mestre — exemplo

Use os materiais deste Bloco como base factual.

Objetivo:
- revisar;
- explicar relações;
- usar exemplos didáticos;
- evitar leitura mecânica;
- não antecipar conteúdo de outros Blocos;
- encerrar com breve recapitulação e perguntas de reflexão.

Idioma e duração são parâmetros de execução, não parte fixa deste prompt.
