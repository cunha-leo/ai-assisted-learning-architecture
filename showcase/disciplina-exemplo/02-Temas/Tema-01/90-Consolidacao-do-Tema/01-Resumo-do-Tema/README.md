# 01 — Resumo do Tema

## Objetivo

Criar uma síntese integrada de todo o Tema depois que os Blocos forem concluídos.

O resumo consolidado não deve ser uma simples concatenação dos resumos individuais.

Ele precisa mostrar:

- quais conceitos aparecem em mais de um Bloco;
- como um Bloco prepara o seguinte;
- quais ideias são centrais e quais são complementares;
- quais exemplos ajudam a conectar o Tema;
- quais dúvidas foram resolvidas;
- quais lacunas ainda existem;
- quais conceitos têm maior probabilidade de reaparecer em avaliação.

## Fontes recomendadas

```text
Resumos dos Blocos
        +
Debates relevantes
        +
Infográficos dos Blocos
        +
Fontes gerais do Tema
        +
Checklist / estado
        ↓
Resumo consolidado
```

## Processo sugerido

1. verificar se todos os Blocos obrigatórios foram concluídos;
2. ler os resumos de fixação;
3. identificar repetições;
4. agrupar conceitos relacionados;
5. perceber progressão entre Blocos;
6. registrar divergências ou nuances;
7. incorporar pontos oficiais do Tema que não apareceram claramente durante os Blocos;
8. produzir uma síntese final;
9. persistir nesta pasta.

## Estrutura sugerida do arquivo

```text
# Tema NN — Resumo Consolidado

## Ideia central
## Conceitos estruturantes
## Relação entre os Blocos
## Métodos / processos
## Exemplos importantes
## Limites e ressalvas
## Pontos que exigem revisão
## Síntese final
```

## Nomenclatura sugerida

`Tema NN - Resumo Consolidado.md`

## Benefício

Esta camada reduz fragmentação. Em vez de lembrar cinco unidades isoladas, o estudante passa a visualizar o Tema como uma única estrutura conceitual.
