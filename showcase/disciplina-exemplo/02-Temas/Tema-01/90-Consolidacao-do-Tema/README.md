# 90 — Consolidação do Tema

Esta camada existe para **subir o nível de abstração** depois que todos os Blocos de um Tema foram estudados.

Ela não serve para simplesmente juntar cinco resumos em um arquivo maior.

O objetivo é revisar o Tema como um sistema único, identificar relações entre os Blocos, corrigir lacunas, eliminar repetições, perceber progressão conceitual e construir uma visão integrada.

## Quando consolidar

Somente depois de verificar que os Blocos previstos para o Tema foram concluídos ou explicitamente dispensados.

Antes de começar, o agente deve checar:

- transcrições existentes;
- capturas relevantes;
- resumos;
- infográficos;
- revisões auditivas;
- Checklist Mestre;
- fontes gerais do Tema.

## Fluxo

```text
Bloco 01 ┐
Bloco 02 ├──┐
Bloco 03 ┤  │
Bloco 04 ┤  ├─→ cruzamento e síntese → consolidação do Tema
Bloco 05 ┘  │
            │
Fontes gerais do Tema ────────────────┘
```

## O que muda em relação ao Bloco

No Bloco, a pergunta é:

> “O que preciso compreender desta unidade?”

Na consolidação, a pergunta passa a ser:

> “Como todas as unidades deste Tema se conectam e o que eu realmente preciso reter como estrutura mental?”

## Resultado esperado

A consolidação pode gerar:

- resumo consolidado;
- mapa de relações;
- infográfico consolidado;
- podcast/revisão auditiva do Tema;
- lacunas de estudo;
- lista de conceitos críticos para avaliação.
