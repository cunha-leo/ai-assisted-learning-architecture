# 02 — Infográfico Consolidado do Tema

## Objetivo

Representar visualmente o Tema completo em uma única peça de revisão.

Ele deve responder:

> “Se eu tivesse poucos minutos para relembrar este Tema inteiro, quais relações e conceitos precisariam estar visíveis?”

## Diferença para o infográfico de Bloco

O infográfico de Bloco aprofunda uma unidade.

O infográfico consolidado deve:

- reduzir repetição;
- mostrar relações entre Blocos;
- destacar progressão conceitual;
- evidenciar ciclos, dependências ou contrastes;
- priorizar os elementos realmente estruturantes do Tema.

## Fontes

```text
Infográficos dos Blocos
        +
Resumo consolidado
        +
Resumos individuais
        +
Fontes gerais do Tema
        ↓
Infográfico consolidado
```

## Formatos possíveis

Dependendo do conteúdo:

- mapa conceitual;
- jornada;
- linha do tempo;
- ciclo;
- matriz;
- arquitetura em camadas;
- fluxo de processo;
- combinação de formatos.

## Critérios de qualidade

Um bom infográfico consolidado deve:

- ser legível;
- evitar excesso de texto;
- mostrar relações, não apenas tópicos;
- permitir revisão rápida;
- representar o Tema inteiro sem virar mural;
- manter coerência visual com os infográficos dos Blocos;
- deixar clara a hierarquia entre conceitos principais e secundários.

## Uso posterior

Pode ser utilizado para:

- revisão pré-avaliação;
- reabertura rápida do Tema;
- apoio a novo debate;
- fonte para revisão auditiva consolidada;
- comparação com material oficial;
- preparação para entrevista, apresentação ou prova.

## Nomenclatura sugerida

`Tema NN - Infografico Consolidado.png`

## Público x privado

Na implementação privada, o artefato pode manter contexto institucional quando útil ao estudo.

Na versão pública, prefira uma composição visual autoral, sem branding que possa sugerir material oficial de terceiros.
