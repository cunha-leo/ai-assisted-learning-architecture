# Disciplina exemplo

Esta pasta demonstra como uma disciplina é representada na arquitetura.

O conteúdo é deliberadamente sanitizado. A estrutura reflete um uso real, mas fontes institucionais restritas não são redistribuídas.

- Tema 01: demonstração mais completa;
- Temas 02–04: estrutura ilustrativa para mostrar escalabilidade;
- consolidação: representada por placeholders e documentação.
